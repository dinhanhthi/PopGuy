# PopGuy Website

The marketing and documentation site for PopGuy, built with React and Vite.

## Development

```sh
npm install
npm run dev
```

## Verification

```sh
npm test
npm run build
```

The site includes Home, Docs, Pricing, and Changelog routes. Download buttons
point to the latest GitHub release, and Get Pro opens the configured Lemon
Squeezy checkout.
